# Reproducibility materials

This archive contains the code and simulated data required to reproduce the analyses in the manuscript "Same Sullivan, different worlds: When prevalence is not health, and lifetables are not mortality.""

All data used in the analysis are simulated. The scripts should be run in numerical order. These scripts, especially steps 03 and 04, should ideally be run on a machine with >=16Gb of RAM and >=8 cores available. For machines with less available resources, some adaptation may be required, and one should expect longer processing times.

Author-identifying metadata have been temporarily removed for double-anonymous peer review. Full attribution and the permanent public repository will be supplied following review.
